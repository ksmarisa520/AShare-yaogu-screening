# data/

| 文件 | 说明 |
|---|---|
| `zt_study.json` | 东财涨停池 / 炸板池 / 跌停池原始缓存，`{"YYYYMMDD": {"zt": [...], "zb": [...], "dt": [...]}}`。96 个交易日 key（2026-06-01 → 2026-10-21），**其中 15 天有数据**（2026-09-23 起）。其余 81 天是全空占位，印证「东财涨停池 API 只保留最近约 1 个月」。 |
| `daily_limitup_summary.csv` | 逐日涨停 / 炸板 / 跌停家数摘要，15 行。最后一行 2026-10-21 是盘中快照，做统计要剔除。 |

## 这个目录是只读种子

`scripts/base_rates.py` 会把它和 `~/.cache/yaogu/zt_study.json` **合并读取**，但**只往用户缓存写**，永远不覆盖本目录。

原因：`zt_study.json` 里 2026-09-23 → 10-21 这段历史已经超出东财 API 的约 1 个月保留期，现在重新抓只会拿到空数组。它是这段样本的唯一副本。

想复现 `docs/01_base_rate_study_2026-10.md` 里的表格：

```bash
python3 scripts/base_rates.py 20260923 20261020 --offline
```
