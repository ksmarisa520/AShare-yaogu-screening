# yaogu-screening

**A 股妖股（连板 / 题材炒作股）启动特征 → 结束特征筛选卡 + 实测晋级率基准表 + 双向可执行性回测 + 可重跑脚本。**

> 定位：这是**情绪仓筛选器**，不是选股器。妖股没有价值底，只有筹码结构与题材热度。
> 一句话用法：**盘后 15:30 跑一遍 → 得到隔日可打的候选 + 手上持有的要不要跑。**

所有阈值都不是拍脑袋写的，而是用东方财富涨停池 / 炸板池 / 跌停池的真实数据，逐日 `当日池 → 次日池` 对撞统计出来的。更关键的是：**这份数据还被拿去做了两个"到底能不能成交、扣成本能不能赚"的回测，结论是——筛选有效，交易无效。** 见 [docs/03](docs/03_forward_backtest_2026-10.md) / [docs/04](docs/04_reverse_backtest_2026-10.md)。

## 快速开始

零依赖，只需要 Python 3.8+（标准库，不用 `pip install`）。

```bash
git clone https://github.com/ksmarisa520/yaogu-screening.git
cd yaogu-screening

# 1) 扫今天的涨停池，按评分排序，标出次日候选 / 持仓退出预警
python3 scripts/scan_zt_pool.py

# 2) 扫指定交易日，顺手吐一份 JSON
python3 scripts/scan_zt_pool.py 20261113 --json out/pick_20261113.json

# 3) 对 A 级候选做二次核查（公告 / 龙虎榜 / 财报日 / 出售回购股份）
python3 scripts/yaogu_pick.py 20261113

# 4) 扫跌停池（X/D/C 分档 + 风险提示命中）
python3 scripts/scan_dt_pool.py 20261113

# 5) 用仓库自带的历史缓存，离线复算基准率表（秒出）
python3 scripts/base_rates.py --offline

# 6) 双向回测
python3 backtest/zt_backtest.py
python3 backtest/dt_backtest.py
```

输出样例（2026-11-13 收盘后实跑）：

字段：`BRD` 连板数、`SEAL@` 首次封板时间、`TURN%` 换手率、`SEAL%` 封单÷流通市值、`SAMT%` 封单÷成交额、`FLOAT` 流通市值（亿）、`BRK` 当日炸板次数、`N` 同日同行业涨停家数、`GRD/SCORE` 评分等级。

> **`SEAL%` 和 `SAMT%` 回答的是两个问题，别混用。** `SEAL%` 是锁仓强度（次日还能不能涨），`SAMT%` 是可成交性（今天你能不能买到）。混用会造成"评级 A 却永远买不到"——全样本假设全成交 +1.44%/笔、实际可成交 −0.06%/笔，差的 1.50% 全在这里。

## 先看这个：筛选有效，交易无效

| 方向 | 路径 | 胜率 | 均值 | 日聚合 t |
|---|---|---|---|---|
| 正向 | 打板 → 次日开盘卖 | 42.8% | **−0.06%** | −0.65 |
| 正向 | 打板 → 次日收盘卖 | 40.9% | **−0.67%** | **−1.65** |
| 反向 | 抄跌停 → 次日收盘卖 | 36.7% | −2.02% | — |
| 反向 | 次日开盘买 → 当日收盘卖 | 52.1% | +1.03% | +1.94（恐慌日 +3.93） |

**正向被可成交性锁死，反向被方向锁死。**

- 涨停的次日溢价（平均缺口 +1.64%）是真实的，但 **100% 锁在"封单强"这一侧，而那一侧 45% 次日一字**，你根本进不去。能买到的那些票，恰好是封不住的那些票。
- 抄跌停在任何分组下都是负期望：隔夜路径胜率只有 **4.2%**。唯一站得住的是「恐慌日 → 次日开盘买 → 当日平」，但它只有 6 个独立观测，赚的是流动性溢价，不是妖股逻辑。

**所以这张卡的正确用法是"筛掉不该碰的"和"管住手上的"，不是"找到能买的"。** 任何用日线数据做出来的打板策略，最好也只能看到 −0.06% 这个数。

## 什么算妖股（先排除，再筛）

| 条件 | 妖股 | 排除（不是妖股） |
|---|---|---|
| 上涨驱动 | 题材 / 标签 / 摘帽 / 重组预期 | 业绩超预期、订单、涨价 |
| 基本面 | 亏损或微利，题材业务营收占比 <5% | 有真实利润与现金流 |
| 筹码 | 小盘 + 股权分散 + 机构近零 | 机构重仓、北向持股 |
| 走势 | 连续涨停、%b>1、均线脱节 | 沿均线缓涨 |
| 分析价值 | 筹码结构 > 估值 | 估值 > 筹码 |

**一句话判别**：把公司自己公告里的「题材业务营收占比」找出来。`<1%` = 纯情绪仓；`>20%` 且有毛利 = 趋势仓，别用这张卡。

**一条新增的硬排除**：查「出售回购股份计划」是否在有效期内。这是唯一能在涨停前一个月就知道的、带明确价格锚的卖压——公司在涨停板上卖自己回购的股票，等于给出一个"愿意卖"的价格，形成天花板。案例见 [docs/06](docs/06_case_600661.md)。

### 两条一票否决

- **当日炸板股，次日再涨停只有 4.3%（n=258）**；对照当日涨停股次日 21.9%（n=649）→ 炸板 = 接力资金断裂，**别等回封**。

> ⚠️ 样本限制（引用时必须说明）：14 个交易日、单一市场环境（震荡偏热，日均 50 家涨停）、样本重叠（同一波连板被多次计数）→ **只能当方向性赔率，不是精确胜率**。

## 启动特征：三层清单

**L0 土壤**（盘前/周末筛，决定进不进观察池）
- 流通市值 20–50 亿（实测 21.5%；<20 亿反而只有 10%）
- 股价 < 10 元，最佳 2–6 元
- 股权分散：控股股东 + 一致行动人 < 20%
- 机构持股近零、零券商覆盖、无目标价
- 基本面「烂得刚好」：亏损或微利，但刚完成债务重组 / 摘帽 / 控股股东变更
- 有可贴的标签，且公司自己承认该业务占比极小
- 板块正处政策催化窗口（同业同日涨停 ≥5 家 → 21.5% vs 孤立 15.3%）
- 近期有事件日历：股东会、激励计划、定增/重组预案
- **没有「出售回购股份计划」在有效期内**（见上）

> ⚠️ 市值这一条是**风格依赖项**。在 2026-10（国证2000 −11.76% 的杀小盘窗口）里，30–60 亿反而是全场最差档（−1.50%），≥120 亿 +0.32%。判断小市值偏好前先看当月市值因子方向。

**L1 点火**（首板当日收盘即可确认）
- 早板：09:25–09:35 封板 → 26.7%（+9.7pt，但见上面的折扣）
- 缩量板：换手 <5% → 23.5–26.0%；>10% 直接放弃
- 封单厚：封单 ÷ 流通市值 ≥2%（31.8%），最好 ≥4%（40%）
- 炸板 0 次（2 次+ 只剩 10.5%）
- 板块集体涨停，且它不是板块最弱那只（最弱者＝资金已换船，一票否决）
- 首板前 60–120 日在 ±10% 箱体内横盘（筹码干净），非下跌通道反弹

**L2 加速**（2 板以上，决定能不能加/续抱）
- 缩量续板：换手 <5% 且封单比不降 → 63.0%
- 封单比 >4% → 77.8%
- 零炸板、封板时间不后移
- 梯队完整：板块有龙头（最高板）+ 跟风（首板）同时存在
- 公司还没发风险提示公告

### 评分卡（满分 15，≥7 进候选，≥9 才考虑打）

| 项 | 条件 | 分 |
|---|---|---:|
| 封板时间 | ≤09:35 / 09:35–10:00 / 其他 | +3 / +1 / −1 |
| 换手 | <5% / 5–10% / 10–20% / >20% | +3 / +1 / −2 / −3 |
| 封单比 | >4% / 2–4% / 1–2% / <1% | +4 / +3 / +1 / −1 |
| 流通市值 | 20–50 亿 / 50–100 亿 / 其他 | +2 / 0 / −1 |
| 炸板 | 0 / 1 / 2+ | +1 / 0 / −2 |
| 板块 | ≥5 家 / 3–4 家 / 孤立 | +2 / +1 / 0 |

直接跑 `scripts/scan_zt_pool.py` 出全表排序。

## 结束特征：八个信号（按可靠度排序）

| # | 信号 | 判据 | 意义 |
|---|---|---|---|
| ① | **封单消失** | 封单÷流通 <1% | 高位股次日晋级率从 50% 掉到 **19.0%** —— 最灵敏的单一指标 |
| ② | **换手放大** | 高位股换手 >10%（尤其 >20%） | 24.4% / 20.0%，对照缩量 63.0% ＝ **派发** |
| ③ | **炸板** | 盘中开板 1 次 / 2 次+ | 0 炸 50.6% → 1 炸 26.9% → 2+ 23.7%；**当日炸板股次日再涨停仅 4.3%** |
| ④ | **板块相对强弱反转** | 同业涨停、它只涨 2–3% 或翻绿 | 资金换船 |
| ⑤ | **公司自己发风险提示** | 《异常波动／风险提示／停牌核查》 | **最硬的空头证据**：公司自曝 PE 倍数、累计涨幅、题材营收占比 |
| ⑥ | **监管动作** | 监管工作函 / 监管警示 / 停牌核查 | 案例：收函后 3 天停牌，复牌 −10%、−10% |
| ⑦ | **龙虎榜由买转卖** | 净买入日 → 2–4 日后净卖出 | **看序列不看单日** |
| ⑧ | **财报窗口** | 财报日 ≤5 个交易日 | 连板撞财报 = 二元赌局 |

**「一日三看」收盘检查（持仓者每天必做，按顺序）**
1. **封住了吗？** 没封 → 第二日开盘竞价处理（不要等反抽）
2. **封单比多少？** <1% → 减半；<0.5% → 清
3. **换手多少？** >10% 且封单薄 → 清；缩量封死 → 可留

**反向陷阱：不是每个「跌」都是结束**
- 首板后 −6% 洗盘再上很常见。判据：**洗盘日不能放量破 MA20**；跌破且放量才叫结束。
- 跌停开盘 + 日内反抽 + 收在跌停附近 = 派发，不是洗盘。

## 妖股的三个死亡方式（尾部风险，止损救不了）

1. **开板即连续跌停** —— 挂单排不上，止损＝滑价 5–8%
2. **停牌核查**（3–5 个交易日锁死）—— 期间板块照跌，复牌补跌
3. **财报暴雷 + 连板高位**

所以：**妖股仓位上限 ≤3%，且不允许「等回本」**。连板股的止损在开板日会失效，这一点必须在任何报告里写明。

## 数据与缓存

- 缓存结构：`{"YYYYMMDD": {"zt": [...], "zb": [...], "dt": [...]}}`，`zt`=涨停池、`zb`=炸板池、`dt`=跌停池。
- 读取时**合并**「仓库自带种子 `data/`」+「用户缓存 `~/.cache/yaogu/`」（同文件以用户缓存为准）。
- 写入**只写用户缓存**，仓库里的种子永不被覆盖——因为那段历史已经超出东财 API 的约 1 个月保留期，覆盖了就再也抓不回来。
- 自定义位置：`YAOGU_DATA` / `YAOGU_CACHE_DIR` 环境变量。
- **回测脚本固定读 `data/`**，不读用户缓存：它们的输入是冻结的研究快照，混入新数据会让文档里的数字无法复现。

**东财涨停池 / 跌停池只保留约最近 1 个月**：用 `beg=20260601` 抓 96 个交易日，只有 15 天回传非空。想要长样本只能每日跑一次、逐日累加。

**盘中快照日会被自动剔除**：`20261021` 那条是盘中抓的，脚本内置 `INTRADAY_SNAPSHOT_DAYS` 常量会跳过它，所以全新克隆上跑 `base_rates.py --offline` 得到的正好是文档里那 14 天窗口。

## 已知限制

1. **跌停池必须用 `sort=fund:asc`。** 沿用涨停池的 `fbt:asc` 会返回 `{"tc": N, "pool": []}`——总数有值、池子为空，看起来像接口废了。这不是接口问题，是排序字段问题；改对之后跌停池完全可用。
2. **龙虎榜数据集常缺最近几日** → 报告要明写「席位明细缺口」，不要用旧数据冒充。
3. **盘中抓池 = 未收市快照**，统计必须剔除当日（脚本已自动剔除）。
4. **ST 股涨跌幅 5%**，与主板 10% 不可混算晋级率；样本池含 ST，要纯主板需自行过滤名称含 `ST` 者。
5. **任何概率都必须标注样本量与窗口**。本卡的数字是 14 个交易日的方向性赔率，**不是胜率承诺**。
6. **只有日线，没有盘口。** 封单量随时间的衰减、撤单率都看不到，所以"能不能成交"这一层就是日线数据的天花板。
7. **不要事后把「已涨 3 板」的票写成「启动特征」**：启动特征只允许用首板当日可观测数据，事后诸葛会让下次完全失效。
